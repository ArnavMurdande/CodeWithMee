## ADR threshold

Create an ADR before changing any of these audited contracts:

- modular monolith versus service boundary;
- PostgreSQL/Prisma authority or migration/cutover strategy;
- authentication/session/organization model;
- `/api/v1` response or authorization conventions;
- private-object or code-execution trust boundaries;
- roadmap ordering or a safe fallback that affects later phases.

Minor implementation choices that remain inside an accepted contract may be recorded directly in this register.
